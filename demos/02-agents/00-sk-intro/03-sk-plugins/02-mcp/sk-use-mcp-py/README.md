# MCP GitHub Integration - Python Version

This is a Python port of the C# MCP (Model Context Protocol) sample that integrates with GitHub tools.

## Note
This is a simplified version of the MCP integration. The original C# version uses the full MCP client with the GitHub server. In this Python version, we simulate the GitHub functionality structure but would need additional MCP Python client libraries for full functionality.

## To extend with full MCP functionality:
1. Install the MCP Python client libraries
2. Set up the GitHub MCP server connection
3. Integrate the MCP tools as Semantic Kernel functions

## Usage
```bash
python main.py
```

The agent will demonstrate GitHub repository querying capabilities.
